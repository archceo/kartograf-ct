# 🧭 Картографический конструктор — ЦТ по географии

Тренажёр-конструктор для подготовки к ЦТ по географии (Беларусь, сезон 2026–2027).
Отдельный самостоятельный сайт, не связанный с геоквестом.

## Что внутри

- **🗺️ Топокарта 1:25 000** — процедурно генерируемый лист: рельеф, горизонтали, река, озеро,
  дороги, мост, деревня, ферма, мельница, колодец, болото, лес, пункт триангуляции,
  километровая сетка. Задания: координаты точки, номер квадрата, объект в квадрате,
  азимут, расстояние, высота.
- **⛰️ Профиль местности** — построение профиля по линии сечения А–Б перетаскиванием точек,
  проверка формы, превышения и максимальной высоты.
- **🌍 Контурная карта** — мир (материки и океаны, координаты, объекты) и Беларусь
  (области, города, реки, озёра, высшая точка).
- **✍️ Географический диктант** — 30 ответов, каждый верный = 1/3 балла.
- **🧪 Вариант ЦТ на 100 баллов** — 10 + 20 + 10 + 10 + 50, с разбором по секциям.
- **📖 Справка** — формат работы, теория по масштабу, азимуту, горизонталям, координатам квадрата.

## Запуск

Просто откройте `index.html` в браузере — внешних зависимостей нет.
Либо локальный сервер:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\serve.ps1
```

и откройте http://localhost:8124/

## Публикация

GitHub Pages: Settings → Pages → Source: Deploy from a branch → `main` / root.
Сайт будет доступен по адресу `https://<логин>.github.io/kartograf-ct/`.
