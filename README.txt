КАРТОГРАФИЧЕСКИЙ КОНСТРУКТОР — отдельный сайт
================================================

Что это
-------
Самостоятельный тренажёр для подготовки к ЦТ по географии.
Не связан с геоквестом: отдельная папка, отдельный сайт, отдельный адрес.

Файлы
-----
index.html  — сам тренажёр (главная страница сайта)
serve.ps1   — локальный сервер, http://localhost:8124/

Как открыть локально
--------------------
1. Двойной клик по index.html — откроется в браузере без сервера.
2. Или запустите serve.ps1:
   powershell -NoProfile -ExecutionPolicy Bypass -File "C:\Users\first\OneDrive\Документы\kartograf-ct\serve.ps1"
   Затем откройте http://localhost:8124/
   С телефона в той же Wi-Fi: http://<IP-компьютера>:8124/

Как опубликовать в интернете (Vercel)
-------------------------------------
1. Откройте https://vercel.com/new
2. Перетащите ЭТУ папку (kartograf-ct) в окно загрузки.
3. Нажмите Deploy.
4. Получите отдельный адрес вида https://kartograf-ct.vercel.app/
   Тренажёр откроется сразу на главной странице.

Важно
-----
- Старый геоквест лежит в соседней папке kvest и на этот сайт не влияет.
- Если правите index.html, после правок задеплойте папку заново.
